---

# 2. KEY ARCHITECTURAL PRINCIPLES
1. **Resource Recovery First**: Setiap material yang masuk ke ekosistem memiliki 
   jalur pengolahan yang jelas menuju mitra industri pengolah terverifikasi.
2. **Decoupled Stateless Architecture**: Compute microservices run in serverless 
   containers (Google Cloud Run), dynamically scaling based on concurrent demand.
3. **Third Normal Form (3NF) Database Integrity**: Fully normalized 12-table PostgreSQL 
   engine with optimized B-Tree indexes, UUID safety, and secure relational cascade boundaries.
4. **Multimodal AI Vision & OCR Pipeline**: Single-roundtrip processing via Gemini 1.5 Flash 
   structured schemas, rate-limited at database levels to control API quotas. AI adalah 
   **pendukung ekosistem**, bukan fitur utama.
5. **PWA & Offline-First Operations**: Employs Service Workers and local caching 
   (IndexedDB/LocalStorage) to allow scans and transactions during offline states, 
   synchronizing logs via background workers when connection is active.
6. **Secure Transactional Ledger**: Immutable financial transactions tracking double-entry 
   token balances for Eco Coins contributions.

## A. PROGRESSIVE WEB APP (FRONTEND LAYER)
* **Framework**: Next.js 14 (App Router) + React + TypeScript + Tailwind CSS + Framer Motion.
* **PWA Configurations**:
  * **manifest.json**: Configured for standalone immersive app shell, custom icons, and theme colors.
  * **Service Worker**: Caches main shells, visual components, page states, and manages background queue synchronizations.
  * **Offline Mode**: Local storage caches scan history and user profiles. Scans captured during 
    offline connectivity are placed in an IndexedDB queue and automatically pushed upon internet recovery.
* **Visual Identity**: Eco-tech clean design with emerald-teal-cyan palette, sustainability-first 
  visual language, frosted-glass morphic controls, fluid transitions, skeleton load states, 
  and full dark-mode assets.
* **Key Pages**: Landing (National Problem → How It Works → Recovery Flow → Partners → Impact → Community → Smart City),
  AI Scanner, Dashboard & Impact Tracking, Pickup Scheduling, Industrial Partner Network, 
  Community & Education, Smart City Dashboard.

## B. ENTERPRISE CORE API (BACKEND LAYER)
* **Framework**: NestJS (TypeScript) with modular component-driven layout.
* **ORM**: Prisma Client connecting to PostgreSQL.
* **Input Validation**: Strict class-validators globally intercept and parse request payloads.
* **Security Middleware**: Auto-injects secure HTTP headers, implements CORS rules, and rate limits.
* **Autoscale Capacity**: Statelessly deployable to Cloud Run (scales down to 0 instances).

## C. MULTIMODAL AI & OCR ENGINE
* **AI adalah pendukung ekosistem, bukan fitur utama.**
* **API Interface**: `google/generative-ai` invoking `gemini-1.5-flash` with structured JSON schema.
* **Functions**:
  1. Primary Waste Classification (PLASTIC, ORGANIC, PAPER, GLASS, ELECTRONIC, METAL, OTHERS)
  2. OCR Parsing (text, barcodes, product identifiers, brand logos)
  3. Eco-Score Calculation (0-100)
  4. Panduan Daur Ulang AI (Indonesian reuse/composting/disposal tips)
  5. Business Insights: volume prediction, processing need forecasting, recycling recommendations
* **Fraud Prevention**: File size validation (max 5MB), MD5 checksum dedup, rate limiting (15/hour).

```

    ↓

    ↓

    ↓

    ↓
```

## B. SMART PICKUP SYSTEM
* **GPS & Geolocation**: Maps integration for Smart Waste Maps (drop points, bank sampah, mitra).
* **Kurir Routing**: Coordinate-based route optimization for pickup logistics.
* **Status Lifecycles**: `PENDING` > `ASSIGNED` > `COMPLETED` > `CANCELLED`.

## C. DIGITAL WASTE BANK SYSTEM
* **Saldo Setoran**: Track deposit balance per user.
* **Histori Setoran**: Complete deposit history with impact metrics.
* **Eco Points & Eco Coins**: Contribution tracking and reward system.
* **BUKAN transaksi jual-beli bebas** — fokus pada kontribusi lingkungan.

## D. SMART IMPACT TRACKING

* Kg CO₂ Terreduksi

# 6. DATABASE SCHEMA DEFINITION
Fully normalized PostgreSQL structure mapped in Prisma (12 tables):
* **users** — Profiles, email, credentials, token balances
* **scans** — AI classification results, OCR text, eco scores
* **pickups** — Pickup requests, driver assignments, coordinates
* **wallets** — Digital currency holdings
* **eco_points** — Point earnings history
* **rewards** — Reward catalog
* **claimed_rewards** — Reward claim records
* **community_posts** — Community updates & alerts
* **analytics** — Community eco impact aggregation
* **education_content** — Educational content library
* **transactions** — Financial transaction log
* **notifications** — In-app notification system
